This is a fintech/backend focused project that focuses on building a fraud-detection API that flags suspicious transactions in real time.

===IMPORTANT===
Make sure to download creditcard.csv from Kaggle to train autoencoder correctly and allow synthetic data generation to work properly.
Link: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
After downloading from link above, put .csv file in archive folder.
